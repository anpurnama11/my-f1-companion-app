# Prototypes

Throwaway code that answers a question. Per `~/.pi/agent/skills/prototype/SKILL.md`:

- Question-driven. The README/docstring at the top says what we're checking.
- One command to run. The run command is at the top of each prototype.
- No persistence. State lives in memory.
- Skip the polish. No tests, no abstractions, no error handling beyond what makes it runnable.
- Delete or absorb when done. Captures the verdict in `NOTES.md` next to the prototype, then the prototype gets deleted.

This directory is not production code. Anything under here is allowed to be ugly.
