# Ticket 02 build plan

**Ticket:** Homepage §1 (favorites nearest-GP pager) + §3 (top speed).
**Status:** in progress.

## Seams (preagreed)

- `Outcome<T>` — sealed Success/Failure/Loading, fold/map, `dataOrNull`.
- UseCase class with `suspend operator fun invoke(...)` taking `HttpClient` injected via `Wiring`.
- `internal fun XxxDto.toXxx()` mapper visible to test only (same module).
- Ktor extension `suspend fun HttpClient.getXxx(): XxxDto` lives in `f1/data/F1Api.kt`.
- VM takes use case as `useCase::invoke` (function ref) → test fake is a plain lambda.
- `MockEngine` + `jsonOk`/`respondError` test harness; `expectSuccess = true`; `String` overload of `respond`.
- JUnit4 (no kotlin.test) per `practices.md` Build floor.
- Pull-to-refresh via `forceRefresh: Boolean = false` propagates `CacheControl.NO_CACHE`.

## Rungs + slices (TDD vertical)

Each slice is one RED→GREEN cycle. Tests are JVM unit only; UI is rendered
in the assemble at the end.

3. **DriverStanding + ConstructorStanding mappers** — toStanding tests.
4. **GetDriversStandingsUseCase / GetConstructorsStandingsUseCase** — 200/4xx/5xx tests.

6. **OpenF1 Ktor extensions** — `getOpenF1Sessions(year, country, sessionName)`, `getOpenF1Laps(key)`. URL assertion test.
7. **GetCircuitTopSpeedUseCase** — country match → max(stSpeed), literal-0 → fallback, fallback-0 → null, multi-circuit country disambiguated by date, pre-2023 → null.
8. **FavoritesCache** — DataStore wrapper, typed keys, atomic edit, read/seedIfEmpty tests.
9. **Circuits.forId(circuitId)** — kebab→Camel mapping for circuit brand accent.
10. **Wiring update** — expose 4 new use cases + FavoritesCache.
11. **HomepageViewModel** — combine 5 use cases, §1/§2/§3 independent, first-launch seed.
12. **Routes.CircuitDetail** + `NavDisplay` entry + click handler in §3.
13. **HomepageScreen UI** — §1 HorizontalPager, §3 card, tap-to-circuit.
